# 1255: Archive orphaned clean pipeline-run directories left un-archived by other sessions

Surface: infra

## Current State

`node bin/residue.js --base 67377db1... --integration-branch origin/main --scope blast-radius`,
run as record #929's wrap-up Phase 3 preamble, found 6 `status: clean` pipeline-run directories
under `.claude-tweaks/pipelines/` belonging to other sessions' runs (not #929's own), never moved
to `.claude-tweaks/pipelines/archive/{run-id}/` per `wrap-up/cleanup-procedures.md` Section B:

- `.claude-tweaks/pipelines/2026-08-21T043316-backlog-standalone`
- `.claude-tweaks/pipelines/2026-08-21T043416-tidy-standalone`
- `.claude-tweaks/pipelines/2026-08-21T043718-backlog-standalone`
- `.claude-tweaks/pipelines/2026-08-21T075653-backlog-standalone`
- `.claude-tweaks/pipelines/2026-08-21T222903-backlog-standalone`
- `.claude-tweaks/pipelines/2026-08-21T224547-backlog-standalone`
- `.claude-tweaks/pipelines/2026-08-21T224609-record-257`

Per `bin/lib/residue/probes/pipeline-runs.js`'s own audit note (#1011): a `status: clean` run dir
is inert regardless of which session's wrap-up produced it, and archival (a move, not a delete)
is non-destructive — safe for any later wrap-up run to apply. This project's
`worktree-always: true` policy makes the move illegal from a feature worktree without
provisioning a dedicated scratch worktree (`_shared/scratch-worktree.md`), which record #929's
own wrap-up judged out of scope for a fix unrelated to its own diff.

**Shaping-time fact-check (2026-08-23):** all 7 directories listed above are no longer present
under `.claude-tweaks/pipelines/` on this machine's main checkout — each already has a matching
entry under `.claude-tweaks/pipelines/archive/`, most likely swept by the automated `reconcile`
archival path (`docs/reconcile-checks.md`) that has run in this repo since this record was
filed. `.claude-tweaks/pipelines/` is gitignored, per-clone local state — this finding may not
hold on a different machine or clone, so the verification step below re-derives current state
rather than trusting this list.

  resolved rather than opening an empty PR.

## Acceptance Criteria

## Technical Approach

Run `bin/residue.js`'s blast-radius scope scan (`bin/lib/residue/probes/pipeline-runs.js`) to get
the authoritative, current list of un-archived `status: clean` run directories — the list in this
record's Current State is a point-in-time snapshot from record #929's wrap-up and may already be
stale (see the shaping-time fact-check above). For whatever the fresh scan reports, move each
directory into `.claude-tweaks/pipelines/archive/{run-id}/` per `wrap-up/cleanup-procedures.md`
Section B — a plain `mv`, non-destructive. Do this from a scratch worktree
(`_shared/scratch-worktree.md`) or the main checkout with a clean tree, since `worktree-always`
policy forbids it from an ordinary feature worktree.

### Key Files

- `bin/residue.js` — the scan command that both discovers and re-verifies the finding
- `bin/lib/residue/probes/pipeline-runs.js` — the `kind: pipeline-run` probe and its staleness note (#1011)
- `.claude-tweaks/pipelines/` — the directories to archive
- `.claude-tweaks/pipelines/archive/` — the destination
- `plugin/skills/wrap-up/cleanup-procedures.md` — Section B, the canonical archival procedure

## Gotchas

- `.claude-tweaks/pipelines/` is gitignored, per-clone local state — the 7 directories this
  record originally named are already archived on at least one machine (confirmed at shaping
  time, 2026-08-23), so this record may resolve to a no-op depending on which clone/machine
  builds it. Always re-run the scan fresh rather than archiving the named list blindly.
- Archival is a `mv`, not a `rm` — always non-destructive, safe to re-run.
- `worktree-always` policy blocks this move from a normal feature worktree; use a scratch
  worktree or the main checkout per `_shared/scratch-worktree.md`.
