# 1909: Instruction-prose diet: operative skill text states the rule and the IL tag, provenance narrative moves out, per-pipeline-step loaded-bytes budget

Origin: brainstorm on #1904 (docs/superpowers/specs/2026-09-05-pipeline-ceremony-cost-design.md, "Filed separately")
Defer-reason: genuinely-larger

**Related:** #1987

## Current State

A `/claude-tweaks:flow` second call (`review,polish,wrap-up`) loads several hundred KB of skill prose before doing any work: `plugin/skills/_shared/` is 1.3 MB, `wrap-up/` alone is 408 KB, `flow/` 348 KB, and each 40 KB file is roughly 10k tokens. Reading the operative files shows that roughly half of most of them is provenance rather than procedure: which record moved a paragraph ("extracted for #887", "split out per #635"), which commit deleted a design doc ("deleted `70849915`"), and retold incident narratives that `docs/incident-log.md` already holds under their `[IL-nn]` tag. The context-cost test (`bin/lib/skill-audit/tests/context-cost.test.js`) caps bytes per file but nothing measures bytes loaded per pipeline step, so the procedure-vs-provenance ratio is invisible. #1765 (fast-lane digest) addresses the same waste for the fast-lane path only; this record is the general case. Tokens, not minutes: prose loading costs money and context headroom (compaction pressure), not wall-clock.

This record is Phase 5 of #1987 (Skill context composer — per-run bundles composed by resolved condition, not per-file ceilings): #1987's Phases 1-4 ship the composer mechanism and its per-step measurement; this record consumes that measurement and does the prose-diet and scaffolding-dedupe pass on top of it.

## Deliverables

- [ ] A stated authoring rule in `docs/skill-authoring.md`: operative text (`## Step N` bodies, gate tables, Next Actions) states the rule and cites the `[IL-nn]` tag or record number; the narrative of why lives in `docs/incident-log.md` or `docs/decisions/`, never restated inline. One sentence of rationale per rule is allowed; a paragraph is not.
- [ ] Per-step composed-bytes measurement is delivered by #1990 (Per-step composed-bytes measurement in context-cost.js) — this record consumes that measurement, not builds it.
- [ ] A first trimming pass over the five pipeline skills plus the `_shared` files they cite, moving provenance out per the rule, with the conformance tests that pin the moved prose updated in the same change (the real cost of this record — every trim moves pins).
- [ ] Before/after bytes per step recorded in the PR description.
- [ ] Inject the Interaction-style directive once from the `SessionStart` hook (`plugin/bin/lib/hooks/session-start.js`) and delete the 35 verbatim copies (501 B each) from every SKILL.md, with the conformance tests that pin that paragraph retargeted to the hook output.
- [ ] Audit the per-skill `## Input`/`## Anti-Patterns`/`## Component-Skill Contract`/`## Next Actions` scaffolding (~260 KB of the 888 KB SKILL.md payload) with `bloat.js`'s existing provenance signals and trim author-facing narration.

## Acceptance Criteria

- [ ] `docs/skill-authoring.md` carries the rule and `harness-health` reports loaded bytes per pipeline step.
- [ ] The five pipeline skills' default-path loaded bytes drop by at least 25% with no change to which steps execute, verified by the existing conformance suites passing after pin updates.
- [ ] No `[IL-nn]` narrative is lost: every trimmed retelling still resolves to its incident-log entry by tag.
