# 1399: declined-learning store: sweep #849's remaining Minor findings (H3 nesting, source naming, TTL)

Surface: backend

## Current State

`#1033`'s Deliverable 4 asked to "sweep the final review's Minor findings for anything worth
folding in at the same time (7 items ...)". The build step dropped this deliverable entirely,
stating the source detail was unrecoverable. Independent review re-verification found that claim
false: `#1033`'s own issue body (its Deliverables section) names 6 of the 7 items with enough
detail to act on. Two of those six were small enough to fix directly during `#1033`'s own
review/polish pass (`reflect/SKILL.md`'s missing `dismissedSubjects` wiring, and the `.gitignore`
comment-block scoping) — see the commit that closed `#1033`.

The remaining three are real but each expands past a same-run fix:

1. **H3 section-nesting cosmetic issue in `full-mode.md`** — the original finding's exact
   location was in `#849`'s SDD-cycle progress notes (`.superpowers/sdd/2026-08-20-declined-learning-store/`),
   which did not survive that run's archival, and `#1033`'s issue body names only the category, not
   a line/section reference. `full-mode.md`'s current heading structure (`## Step 2` → `### Finding
   Shape` / `### Near-misses Chain Walk` / `### Friction Lens` / ... / `### Prior-decline
   annotation` / `### Reflection Insights`) reads as consistently nested today — whatever the
   original cosmetic issue was, it may already be moot after `#1033`'s own edits to this file, or it
   needs a fresh read against the file as it stands now rather than chasing an unrecoverable
   original pointer.
2. **`source: 'wrap-up'` naming when reflect runs standalone** — `full-mode.md`'s "Don't capture"
   resolution hardcodes `source: 'wrap-up'` on `recordDecline`, even when `/claude-tweaks:reflect`
   runs standalone (not invoked from `/claude-tweaks:wrap-up`). Functionally harmless today (every
   reader of this source value — the Prior-decline exact-hash lookup, and the `#1033`
   subject-scan `listDeclined({ source: 'wrap-up' })`, including the fix already made to
   `reflect/SKILL.md`'s own standalone judge-dispatch payload — filters by the same literal
   `'wrap-up'` string), but the name is misleading when the run wasn't actually invoked from
   wrap-up. A rename (e.g. to `'reflect'`) touches every one of those call sites plus
   `tests/bin-lib/declined-learning/store.test.js`'s fixtures that assert on the literal string —
   a coordinated rename across multiple files and their tests, not a one-line fix.
3. **No pruning/TTL on the declined-learning store** — `plugin/bin/lib/declined-learning/store.js`
   has no expiry or size cap; every decline ever recorded (across `/feedback` and `/wrap-up`
   reflect) accumulates in `.claude-tweaks/declined-learning/store.json` forever. This is a real
   design gap (unbounded growth, and a stale decline from months ago can still suppress or
   annotate a finding today), not a sweep-able one-liner — it needs a design decision (age-based?
   count-based? per-source?) before it can be built.

## Technical Approach

Three independent sub-changes, each safe to land separately:

1. **H3-nesting check** — read `plugin/skills/reflect/full-mode.md`'s `## Step 2` heading tree
   fresh; either it's already clean (close as moot, note why in the closing commit) or fix the
   specific nesting defect found.
2. **`source` rename** — pick a name accurate for both invocation paths (e.g. `'reflect'`) and
   apply it atomically across every `recordDecline`/`listDeclined`/filter call site: both
   `recordDecline(...)` and `listDeclined({ source: ... })` calls in `full-mode.md`, the
   `listDeclined({ source: 'wrap-up' })` call in `SKILL.md`'s transcript-judge integration
   paragraph, and every literal `'wrap-up'` fixture in `store.test.js`. No caller outside
   `plugin/skills/reflect/` and its test suite reads this field.
3. **Pruning/TTL** — add a `pruneDeclines` (or equivalent) export to `store.js` following its
   existing `withLock`/`readStore`/`writeStore` read-modify-write pattern; decide the policy shape
   (age-based on `declinedAt`, count-based, or both) before implementing; wire a call site into a
   health-sweep or `/claude-tweaks:reconcile` cache-cleanup path per `docs/reconcile-checks.md`'s
   registration procedure if that's the chosen home.

## Gotchas

- The H3-nesting finding's original location (`.superpowers/sdd/2026-08-20-declined-learning-store/`)
