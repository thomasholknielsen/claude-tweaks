# 1424: residue.js/tidy worktree scan ignores uncommitted working-tree changes — a dirty worktree classifies as safely deletable

Origin: reflect full (conversation wrap-up, tidy-followups)

Defer-reason: tangential

## Current State

`bin/residue.js`'s `kind: worktree` findings report locked/unlocked state, branch, and reaper-domain membership (`bin/lib/residue/scope.js`), and `/claude-tweaks:tidy`'s Step 4.5 orphan classification judges deletability from committed history (`git rev-list --count main..branch`, patch-equivalence). Neither consults working-tree state. Observed live 2026-08-24 (tidy run `2026-08-24T134857-tidy-standalone`): worktree `agent-a88609ef5fb7214cb` classified as safely deletable (0 commits ahead, branch fully merged) while holding a complete, uncommitted `fileToolTargetPath` dedup refactor in its working tree. Only `git worktree remove`'s own "contains modified or untracked files" refusal prevented data loss — an accidental backstop, and the report's Yours row even offered `--force` as the follow-up, which would have destroyed the work. The refactor was later verified (34/34, 592/592 tests) and shipped as PR #1401.

## Deliverables

- `bin/residue.js` `kind: worktree` findings gain a `dirty` evidence field: `git -C {path} status --porcelain` non-empty (uncommitted or untracked files present).

- `/claude-tweaks:tidy`'s Step 4.5 classification (scan-procedures.md) routes a dirty worktree to Yours with the changed-file list — never to the Approve delete batch, and never with a bare `--force` suggestion — regardless of committed-history merge state.

- A `tests/bin-lib/residue` case pins the `dirty` field (fixture worktree with an uncommitted file → `dirty: true`; clean → `dirty: false`).

## Acceptance Criteria

- A worktree with 0 commits ahead but a dirty working tree is reported `dirty: true` by `bin/residue.js` and lands in tidy's Yours section with its changed files named.

- The scan-procedures.md classification table names working-tree dirtiness as a Yours-routing condition.

- The new residue test passes; existing residue tests unchanged.
