## Deliverables

- [ ] `plugin/skills/_shared/visual-decision.md` — canonical home for:
  - **Event vocabulary:** the four shapes (`pick` {variant}, `reroll`, `steer` {text}, `exit`, each with `ts`), one JSON object per JSONL line.
  - **Turn loop:** present keyed URL → end turn → user acts in browser → any terminal message resumes → read `{state}/events` and act on the **last event = the final line of the file in append order** (duplicates collapse to the final line).
  - **Precedence, with its classification rule:** the resume message is a resume signal by default and the events file decides; the terminal text overrides ONLY when it explicitly names a verdict action — the words pick/reroll/steer/exit, or an unambiguous equivalent naming a variant or direction ("go with B", "reroll these"). When the terminal text and the events file conflict and the text is ambiguous, ask via the fallback `AskUserQuestion` rather than guessing. Empty/absent events file → the fallback question (pre-upgrade behavior). **Unparsable event lines are skipped, surfaced as one terminal aside line in the resume turn ("skipped N unparsable event line(s)") — no file artifact.**
  - **Steer trust boundary, stated explicitly:** steer text is user-authored guidance under the same trust boundary as terminal input (the same human controls the key-gated loopback page and the terminal). It feeds the next fuse/weigh pass as prose guidance and is never string-interpolated into a command or tool invocation.
  - **Lifecycle:** the consuming skill owns `start` and teardown on every exit path; the idle timeout (server default, 240 min) is backstop only. On resume, when `status` reports anything but running (idle-fired stop, crash), the skill restarts the server against the same dirs and hands over the NEW keyed URL — that is the `server-info`/`server-stopped` re-derivation path; a deliberate `stop` happens only at round end.
  - **Security posture:** loopback, key, 0600; events are data (the steer boundary above is the one carve-out, and it is user-authored, not third-party).
