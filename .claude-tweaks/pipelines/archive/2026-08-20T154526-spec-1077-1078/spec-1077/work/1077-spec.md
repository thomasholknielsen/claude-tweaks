# 1077: Relocate QA artifact paths to .claude-tweaks/artifacts/ across writer skills and init gitignore

Surface: backend

## Current State

QA/browser artifacts are written to project-root directories in consumer projects. The writer/reader conventions, with their exact locations in this repo:

- `plugin/skills/test/qa-procedures.md:45-46` — `SCREENSHOTS_BASE` default `screenshots/qa`, `TRACES_BASE` default `traces`; lines 73-79 build `RUN_DIR="screenshots/qa/{YYYYMMDD}_{HHMMSS}_{hex}"` (including a `node -e` snippet at line 75 and an example at line 79)
- `plugin/skills/test/qa-reporting.md:176-177,258` — trace paths `traces/{id}/{ts}.zip` in the findings table and report footer
- `plugin/agents/qa-agent.md:23,329` — `TRACES_BASE` default `traces/`; REPORT_JSON example trace path
- `plugin/skills/browse/SKILL.md:78-88` — `screenshots/browse/<session>/<NN>_<description>.png` and `traces/<session>/<timestamp>.zip` conventions
- `plugin/skills/browse/agent-browser-reference.md:131-140` — trace-stop path convention and a "`traces/` … belongs in `.gitignore`" guidance note
- `plugin/skills/visual-review/SKILL.md:169`, `browser-review.md:24,60,193-194`, `page-mode.md:16,27,49-51,88,185-189`, `journey-mode.md:27-35,108,117`, `discover-mode.md:83,99-101` — screenshot/trace path conventions and illustrative example paths; `browser-review.md:60` globs `screenshots/qa/*/report.json` as a **reader**
- `plugin/skills/stories/SKILL.md:351` — "`traces/` and `screenshots/` are tooling residue … ensure both are gitignored"; `refine.md:25,43,49` — trace paths in the refine loop
- `plugin/skills/journey-health/SKILL.md:97` — **reader**: globs `screenshots/qa/*/report.json` for recent QA evidence
- `plugin/skills/help/context-flow.md:74-75,82` — artifact-path cells in the skill I/O table
- `plugin/skills/init/bootstrap/step-04-gitignore-suggestions.md` — suggested gitignore block contains a bare `screenshots/` line but no `traces/` (a pre-existing inconsistency), and its migration table has no row for the artifact paths

Top-level `screenshots/` and `traces/` are plugin state polluting the user's project root; `.claude-tweaks/` is the established home for plugin-local state (`pipelines/`, `research/`, health caches). Artifacts live in a flat namespace there rather than under per-run `pipelines/{run-id}/` dirs because they are minted standalone (ad-hoc `/browse`, standalone `/stories` — no run dir exists) and because run-dir `work/` is committed audit trail that binary zips/PNGs must never ride — full rationale on parent #1075.

## Deliverables

1. Every artifact path convention above moves under `.claude-tweaks/artifacts/`, preserving the internal shape as a prefix-only change: `screenshots/qa/…` → `.claude-tweaks/artifacts/screenshots/qa/…`, `screenshots/browse/…` → `.claude-tweaks/artifacts/screenshots/browse/…`, `traces/…` → `.claude-tweaks/artifacts/traces/…`. Preserve each file's existing trailing-slash form verbatim (e.g. `traces` in `qa-procedures.md:46` vs `traces/` in `qa-agent.md:23`) — no normalization. Writers and readers (`journey-health/SKILL.md:97`, `visual-review/browser-review.md:60` report.json globs) change together — a reader globbing the old path against a writer writing the new one is the failure mode this sub-issue must not ship.
2. `plugin/skills/init/bootstrap/step-04-gitignore-suggestions.md`, two precise edits:
   - **Base suggested block** (what fresh projects get): the bare `screenshots/` line is **replaced** by a single `.claude-tweaks/artifacts/` line. One line, not per-subdir lines — nothing under `artifacts/` is ever committed (unlike `pipelines/*/work/`), so the blanket-line un-ignore trap the file documents for `pipelines/` does not apply; this matches the existing `.claude-tweaks/research/`-style entries. State that safety condition in the file's explanation paragraph.
   - **Migration table**: one new row. Trigger: `.gitignore` contains a bare root-level `screenshots/` line (the pre-relocation suggestion), with or without a `traces/` line. Action: add `.claude-tweaks/artifacts/`, and keep the legacy `screenshots/` line plus add a legacy `traces/` line so old trees stay ignored while they still exist on disk; note both legacy lines become removable once the artifacts residue probe (#1078) has surfaced and cleaned the legacy trees.
3. Gitignore-guidance prose updated to the new home: `stories/SKILL.md:351`, `browse/agent-browser-reference.md:140` (both currently instruct gitignoring the root-level dirs).
4. One conformance test pinning the writer/reader pair: `qa-procedures.md`'s `SCREENSHOTS_BASE` value and the two reader globs (`journey-health/SKILL.md`, `visual-review/browser-review.md`) all carry the same `.claude-tweaks/artifacts/screenshots/qa` prefix. This is the one contract-shaped path relationship whose silent drift re-creates the split-reader bug; the illustrative example paths elsewhere are deliberately not pinned.

- `grep -rn "screenshots/qa\|screenshots/browse\|traces/" plugin/` returns only occurrences prefixed by `.claude-tweaks/artifacts/`, with exactly two classes of allowed exceptions: (a) the init migration-table row's deliberate description of the legacy convention, and (b) `visual-review/journey-mode.md:117`'s retention sentence, which #1078 rewrites — this record changes only that file's path-prefix lines, not line 117.
- A whitespace-spanning control (`grep -rzn` or `\s+`-joined pattern) over the same tokens finds no line-wrapped stragglers.
- The two reader globs (`journey-health/SKILL.md`, `visual-review/browser-review.md`) match the writer's new RUN_DIR convention exactly, and the new conformance test (Deliverable 4) proves it red-green: it fails when either side's prefix is reverted.
- `plugin/agents/qa-agent.md`'s `TRACES_BASE` default and REPORT_JSON example agree with the new convention.
- init's suggested gitignore block parses as valid gitignore syntax, keeps the existing per-level `pipelines/` pattern byte-identical, and no longer carries a bare `screenshots/` line in the base block.
- No touched `SKILL.md` exceeds its pinned byte ceiling (the ceiling conformance suite in `npm test` passes; measured at specification time, the tightest file — `journey-health/SKILL.md`, 38,707 bytes — has ~2.2KB headroom against the 40KB ceiling).
- Full `npm test` passes.

## Technical Approach

A mechanical prefix sweep, file by file, over the inventory in Current State — no semantic redesign, no renaming of the `<session>`/`{run}`/`<story-id>` sub-structure. Derive the final file list by re-running the sweep greps rather than trusting this inventory (files may have moved since specification): grep for `screenshots/` and `traces/` (and their regex-escaped forms) across `plugin/`, then apply the edits. For the init gitignore file, follow the file's own existing structure: the block, the explanation paragraph, and the migration table each get their edit in the established format per Deliverable 2.
