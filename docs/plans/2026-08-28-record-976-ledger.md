| 1 | review | Lens 3b (Security): `git-command.js`'s `isReadOnlyApply()` checks only whether ANY of `--check`/`--stat`/`--numstat`/`--summary` is present in a `git apply` invocation's args. Per git's documented semantics, `--apply` explicitly overrides all four of those "turns off apply" flags and re-enables real application. `isReadOnlyApply(['--check', '--apply'])` therefore returns `true`, so `gitTargets('git apply --check --apply x.patch', dir)` resolves `[]` (no write target) even though the command actually applies the patch — a fail-open bypass of the exact gate #976 exists to close. Empirically reproduced: `gitTargets('git apply --check --apply x.patch', '/repo')` → `[]`. | open | Staged as patch — `staged/review-1.patch`. Awaiting Review Console approval. |
