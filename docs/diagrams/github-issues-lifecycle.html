How claude-tweaks Works with GitHub Issues

Three watchdog skills judge the repo and file deduplicated issues (only code-health and harness-health feed the authorized-build pipeline below — journey-health findings are reviewed directly by a human). A human-gated triage step is the only path that authorizes work; the label it applies is a maintainer's signature, since an issue body is untrusted, prompt-injectable input. A claim-safe dispatcher then hands authorized issues to the normal build pipeline, which closes them only by merging a carrier commit — never by calling gh issue close directly.
